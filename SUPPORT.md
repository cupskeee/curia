# Support

Curia is a pre-alpha, volunteer-run project with a single maintainer. There is no
release yet. Nothing here is a promise of a response time or of a fix.

## Where to go

| You want to | Go to |
|---|---|
| Report a bug in the app or the mod | [GitHub Issues](https://github.com/cupskeee/curia/issues), "Bug report" form |
| Suggest a feature | GitHub Issues, "Feature request" form |
| Report that Curia works or fails on Windows or Linux | GitHub Issues, "Tester report" form. The maintainer can only test on macOS, so these reports are the only way Windows and Linux behaviour gets verified. |
| Report a security problem | Do not open an issue. Use [private vulnerability reporting](https://github.com/cupskeee/curia/security/advisories/new) and read [SECURITY.md](SECURITY.md). |
| Report a conduct problem | Email the address in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |
| Understand how Curia is meant to work | The [README](README.md) and the documents in [`docs/`](docs/) |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

Search existing issues first. Blank issues are disabled; use one of the forms.

## What to include in a bug report

- Curia app version and mod version, and where you got them.
- Operating system and version, and CPU architecture.
- Crusader Kings III version and display mode (Fullscreen or Windowed).
- Whether the problem happens every time, and the exact steps.
- What you expected and what happened instead.
- Optionally, a short excerpt of the Curia app log, trimmed to the relevant lines.

## What never to include

- API keys or tokens, in any form. If you pasted one by mistake, revoke it at your
  provider now and edit the post.
- Full log files. Logs can contain realm details you may not want public, and CK3's
  own `debug.log` and `error.log` are large. Paste only the few lines that matter.
- Paradox game files or `script_docs` / `dump_data_types` output.

## Out of scope

- Help with Crusader Kings III itself, other mods, or your LLM provider's account,
  billing or rate limits.
- Anything that requires launching CK3 in debug mode or using the console. Curia
  never needs either, and both disable achievements. If a problem seems to need
  them, say so in the issue instead of trying it.
